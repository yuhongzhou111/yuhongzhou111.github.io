# Yuhong Zhou — personal website

Static HTML website prepared for GitHub Pages.

## Publish

Create a repository named `yuhongzhou111.github.io` and place these files at its root. Push the `main` branch, then choose **GitHub Actions** under **Settings → Pages**. The workflow in `.github/workflows/deploy.yml` publishes the site automatically.

The address will be `https://yuhongzhou111.github.io/`.
